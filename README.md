# CipherForge-BioTriplex

Privacy-preserving fine-tuning of TinyLlama-1.1B-Chat on the **BioTriplex**
gene–disease relation QA benchmark (7-class coarse / 21-class fine-grained
GenRel classification), using the CipherForge three-party framework:

- **Plaintext LoRA baseline** (`single_process`) — HuggingFace Trainer + PEFT.
- **CipherForge three-party RMS-PIR** (`three_party`) — BFV homomorphic
  encryption + RMS-PIR private row selection + PRG masking + differential
  privacy (d-χ), so the label never leaves the user (U) side and the server (S)
  never learns which rows are queried.

## Highlights

| Task | Split (train/val/test) | Zero-shot | Plain LoRA | RMS-PIR (DP) |
|---|---|---:|---:|---:|
| BioTriplex-7  | 734 / 134 / 203 | 0.192 | 0.611 | **0.670** |
| BioTriplex-21 | 801 / 149 / 230 | 0.078 | 0.200 | **0.296** |

Test-set accuracy on the same evaluation protocol
(letter-token logits at the answer position). Detailed per-run metrics, logs
and loss curves live under [`results/`](results/).

## Data

The raw BioTriplex corpus is a third-party dataset
([BioTriplex-results](https://github.com/0aabgu/BioTriplex-results) — official
repository with full text, annotations, and preprocessing code). This repo
ships the **processed QA JSONL** generated by
`single_process/cipherforge/src/data/biotriplex_dataset.py`:

- `single_process/data/BioTriplex` — 7-class coarse GenRel QA (train 734 / val 134 / test 203)
- `single_process/data/BioTriplex-21` — 21-class fine-grained GenRel QA (train 801 / val 149 / test 230)
- `single_process/data/BioTriplex-obal` / `BioTriplex-21-obal` — oversampled-balanced variants
- `single_process/data/BioTriplex-shorter` — NER-generation task data

To regenerate from the raw corpus, point `biotriplex_dataset.py` at the
`Preprocessed BioTriplex/` directory and run the classification/generation
builders.

## Quickstart

Environment: Python 3.12, PyTorch, Transformers, PEFT, SEAL-Python (see
`single_process/environment.yml` / `requirements.txt`).

```bash
# 1) Plaintext LoRA baseline (example: BioTriplex-7)
python single_process/baseline/scripts/finetune_plain.py \
  --model_id <TinyLlama-1.1B-Chat-v1.0> \
  --data_dir single_process/data/BioTriplex \
  --out_dir runs/plain7 --max_seq_len 2048 --epochs 6 --batch_size 4

# 2) Three-party RMS-PIR fine-tuning (BioTriplex-7 profile)
cd three_party
python coordinator/main.py --config coordinator/three_party_config_rms_biotriplex7.json

# 3) Evaluate an adapter on the test set
python three_party/coordinator/evaluate_auprc.py \
  --model_id <TinyLlama-1.1B-Chat-v1.0> \
  --adapter runs/plain7 --data single_process/data/BioTriplex/test.jsonl \
  --task_type biotriplex7 --max_seq_length 2048
```

> Note: config files contain absolute paths from the original AutoDL server
> (`/root/...`); update them for your environment. Adapters, checkpoints and
> the encrypted databases are **not** stored in this repo.
