# 差分隐私模块迁移变更清单（2026-08-19）

> 用途：让**另一台设备**精准拉取、替换本仓库中与差分隐私（dχ-privacy）模块
> 相关的文件。做法：进入 `CipherForge-ClinVar` 仓库根目录，对下表每个文件执行
> `git checkout <commit> -- <路径>`（或直接按路径覆盖），随后按 §4 验证。

## 1. 版本与提交

- GitHub 仓库：`https://github.com/changrayhan/CipherForge-ClinVar`
- 分支：`main`；本变更对应提交：**`c2bb7b5` 之后的后续提交（见 `git log -1`）**
- 目录：三进程版全部位于仓库根下的 `three_party/`；本文档路径均相对
  `three_party/` 目录。

## 2. 变更内容一句话

把差分隐私模块 `shared/core/dchi_privacy.py`（参考实现
`CipherForgeCode/SLG-HE-PIR/src/core/dchi_privacy.py`）迁入三进程版并**默认开启**
（`dp_enable: true`）：U 端在 `H_U` 交给 M 之前注入多元拉普拉斯噪声；同时做
两处 ClinVar 适配——①batch 键映射（`output_ids` → 二分类 `labels`，使 CTI 与
答案位置噪声语义生效），②噪声半径采样向量化（由逐元素 CUDA 循环改为单次
`exponential_` 求和，步时从 ~15s 恢复到 ~0.4s）。

## 4. 替换后的验证步骤（在目标设备上）

```bash
export CF_MODEL_PATH=/path/to/tinyllama-snapshot
export PYTHON=$(which python)
export REPO_ROOT=$(pwd) PYTHONPATH=$(pwd) HF_HUB_OFFLINE=1

# 三进程冒烟（默认配置已开启 DP；首次会自动复用/生成密钥与密文库）
cd three_party
python -u -s party_s/main_s.py --port 9003 --db_dir party_s/db --device cpu &
python -u -s party_m/main_m.py --port 9002 --keys_dir party_m/keys &
sleep 4
python -u -s coordinator/main.py \
  --config coordinator/three_party_config.json \
  --max_train_steps 20 --batch_size 4 --log_freq 5
```

预期：

- 日志出现 `[PartyU] H15 privatizer attached (alpha=0.15, beta=0.5)`，
  **不再出现** `H15Privatizer import failed`；
- 日志出现 `[PartyU] DP activated: eta_ctx=900 eta_ans=450 noise_l2_ctx=2.29
  noise_l2_ans=3.5x`；
- 训练 20 步无 PIR/密文错误，loss_ce 正常波动，稳态步时 ~0.4-0.8s；
- 若出现 `CUDA error: unknown error`（WSL GPU 上下文偶发污染），重试一次或
  `wsl --shutdown` 后重跑即可。

## 5. 注意

- 关闭 DP：把两个配置里的 `dp_enable` 改为 `false`（其余 `dp_*` 参数可保留）；
- `dp_eta0=900` 为显式校准值；若要使用 EMA 校准，设置
  `dp_calibration_mode: true` 并配合 `dp_calibration_steps`（注意：当前协调器
  没有“校准后自动切换”的运行时开关，校准模式下训练全程不加噪）；
- DP 加噪会带来精度-效用权衡，正式全量训练前建议重新标定；
- 密钥/密文库/检查点/adapter 均为运行产物，不入 Git，无需从仓库拉取。
